# Limbo-OS-launcher
## 🚀 Installation & Setup

1. **Download the APK**
   * Go to the **Releases** section of this repository and download the latest `app-debug.apk` (or release APK) directly to your Android device.

2. **Install the App**
   * Open the downloaded `.apk` file on your device using your File Manager and install it.
   * *If prompted, grant permission to install apps from unknown sources.*

3. **Set as Default Launcher**
   * Once installed successfully, open your device's **Settings**.
   * Navigate to **Apps** (or *Applications*).
   * Search for **Limbo Launcher** and select it.
   * Tap on **Home app** (or *Default home app / Startbildschirm*).
   * Select **Limbo Launcher** to set it as your default home screen.

---

## 🎮 How to Use

* **Open App Drawer:** Tap the **`[::]`** icon at the top of the left sidebar to show or hide all installed applications.
* **Pin Apps to Dock:** Long-press any app in the App Drawer to pin it directly to the left sidebar for quick access.
* **Unpin Apps:** Long-press any pinned app in the left sidebar to remove it from your dock.
* **Search Apps:** Use the top search bar inside the App Drawer to quickly find any application by name.
